# Database Query Analysis Prompt

Analyze the following PostgreSQL query performance data and provide optimization recommendations.

## Input Data
```json
{{query_data}}
```

## Analysis Tasks

1. **Slow Query Analysis**: Identify queries exceeding threshold
2. **N+1 Detection**: Find repeated single-row lookups
3. **Index Utilization**: Review index usage patterns
4. **Query Pattern Analysis**: Detect anti-patterns

## Output Format

### Summary
- Total queries analyzed: X
- Slow queries (>Yms): Z
- N+1 patterns detected: N
- Missing index candidates: M

### Critical Queries (Fix First)
```sql
-- Query 1: [description]
-- Avg: X ms, Calls: Y
-- Issue: [root cause]
-- Fix:
[optimized query or index recommendation]
```

### N+1 Pattern Detection
```
Pattern: [query pattern]
Occurrences: [count]
Likely ORM source: [model/relationship]
Fix: Use [select_related/prefetch_related/join]
```

### Index Recommendations
```sql
-- High priority
CREATE INDEX CONCURRENTLY idx_[table]_[columns]
ON [table] ([columns])
WHERE [condition];  -- if partial index applicable

-- Medium priority
[additional indexes]
```

### Query Optimizations
1. **[P0]**: [Critical query rewrite]
2. **[P1]**: [Index additions]
3. **[P2]**: [Query restructuring]

### PostgreSQL-Specific Recommendations
- [ ] Connection pooling (PgBouncer)
- [ ] Query plan cache review
- [ ] Vacuum and analyze schedule
- [ ] Partitioning for large tables
