# Memory Profiling Analysis Prompt

Analyze the following memory profiling data to identify leaks and optimization opportunities.

## Input Data
```json
{{memory_data}}
```

## Analysis Tasks

1. **Memory Growth Pattern**: Identify if there's a leak or expected growth
2. **High-Impact Lines**: Find lines with largest memory increments
3. **Object Retention**: Identify potential object retention issues
4. **Peak Memory**: Determine peak usage and when it occurs

## Output Format

### Summary
- Peak memory: X MB
- Net change: [+/-Y MB]
- Leak detected: [Yes/No/Possible]
- Severity: [Critical/High/Medium/Low]

### Top Memory Consumers
```
1. [file:line] - [function]
   Memory: +X MB
   Context: [brief description]
   
2. [file:line] - [function]
   ...
```

### Memory Leak Analysis
```
Suspected leak locations:
- [location]: [evidence]
- [location]: [evidence]
```

### Optimization Recommendations
1. **[P0]**: [Immediate fix for critical issues]
2. **[P1]**: [High-impact memory reduction]
3. **[P2]**: [Code quality improvements]

### Memory-Specific Patterns to Check
- [ ] Generators vs lists
- [ ] String concatenation
- [ ] Cache size limits
- [ ] Object pooling opportunities
