# Plan

Research, design, and create a comprehensive implementation plan.

## Workflow

### 1. Research
- Explore existing codebase patterns
- Identify related implementations
- Understand dependencies and constraints

### 2. Architecture Design
For complex systems, design:
- Component architecture
- Data models and API contracts
- Integration points
- Security considerations

### 3. Task Breakdown
Create actionable tasks:
- **Small**: 2-4 hours max
- **Testable**: Clear done criteria
- **Ordered**: Logical sequence

### 4. Output: PLAN.md

Create a structured plan with:
- Overview (what and why)
- Success criteria (measurable outcomes)
- Technical design (architecture, data models, API contracts)
- Implementation phases with tasks, agents, and estimates
- Testing strategy (unit, integration, E2E)
- Risks and mitigations
- Open questions

- [ ] Success criteria measurable
